Quadratics & Exponent Rules

The highest-frequency object on the ALEKS test, worked from a labeled diagram, then drilled with problems you check yourself.

01 Read a parabola before you solve one

Every quadratic question is really a question about this one shape. Know these four landmarks cold before touching the formula.

roots: where the curve crosses the x-axis
vertex: the turning point, min or max
y-intercept: value at x = 0, i.e. "c"
discriminant sign tells you the root count
D > 0  →  2 real roots (crosses twice)
D = 0  →  1 real root (touches once)
D < 0  →  0 real roots (never crosses)
vertex x = −b / 2a

02 Worked example — quadratic formula

Solve 2x² + 3x − 5 = 0 for exact values of x.

1
a = 2,   b = 3,   c = −5 Read the coefficients straight off the standard form ax² + bx + c.
2
D = b² − 4ac = 9 − 4(2)(−5) = 9 + 40 = 49 Compute the discriminant first — 49 is a perfect square, so you already know the roots will be rational.
3
x = (−b ± √D) / 2a = (−3 ± 7) / 4 Plug straight into the formula. Keep the ± until the very last step.
4
x = 4/4 = 1   or   x = −10/4 = −5/2 Split into the two branches and simplify each fraction fully — ALEKS wants reduced form.

03 Worked example — completing the square

Solve x² + 6x + 4 = 0 by completing the square.

1
x² + 6x = −4 Move the constant to the other side first.
2
half of 6 is 3,   3² = 9 Take half the x-coefficient and square it — that's the number that completes the square.
3
x² + 6x + 9 = −4 + 9 Add it to both sides to keep the equation balanced.
4
(x + 3)² = 5 The left side is now a perfect square binomial by construction.
5
x + 3 = ±√5  →  x = −3 ± √5 Square-root both sides, don't forget ±, then isolate x.

The trap ALEKS sets: an expression with a negative exponent buried inside a power of a power, e.g. (2x⁻³y²)⁻². Work from the inside out, one rule at a time — never try to do two rules in one mental step.

05 Practice — check yourself honestly

Work each on paper before opening the answer. If you open it first, you're not practicing, you're reading.

1. Solve using the quadratic formula: 3x² − 5x − 2 = 0

Show answer
D = 25 + 24 = 49  →  x = (5 ± 7)/6  →  x = 2  or  x = −1/3

2. Solve by completing the square: x² − 4x − 1 = 0

Show answer
x² − 4x + 4 = 1 + 4  →  (x−2)² = 5  →  x = 2 ± √5

3. Without solving, use the discriminant to state how many real roots x² + 2x + 5 = 0 has.

Show answer
D = 4 − 20 = −16, D < 0  →  zero real roots

4. Find the vertex of y = x² − 6x + 5.

Show answer
x = −b/2a = 6/2 = 3,   y = 9 − 18 + 5 = −4  →  vertex (3, −4)

5. Simplify: (3x⁻²y³)² · x⁵

Show answer
(3x⁻²y³)² = 9x⁻⁴y⁶  →  ·x⁵ = 9x²y⁶

6. Simplify: (2a⁵b⁻²) / (8a²b⁻⁵)

Show answer
= (1/4) · a⁵⁻² · b⁻²⁻(⁻⁵) = (1/4)a³b⁵ = a³b⁵/4

7. A quadratic word problem: a ball's height is h(t) = −16t² + 48t. At what time(s) does it hit the ground (h = 0)?

Show answer
−16t² + 48t = 0  →  −16t(t − 3) = 0  →  t = 0 or t = 3 seconds

Before you close this

You should be able to look at any quadratic and immediately state its discriminant sign without finishing the solve — that instinct alone answers a chunk of ALEKS questions faster than full computation. If problems 1–4 above took more than 3 minutes each, repeat this section tomorrow morning before moving to Day 2.
